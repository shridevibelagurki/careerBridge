careerBridge
Connecting Talent to Opportunity

CareerBridge is a frontend career management platform designed for freshers and experienced professionals. It helps users create resumes, track job applications, save job opportunities, and monitor placement readiness — all within a simple and responsive interface.
This project is built entirely with frontend technologies and stores data locally in the browser.

Features

Dashboard
View job listings, saved jobs, and key statistics in one place.

Resume Builder
Create professional resumes using fresher and experienced templates with live preview functionality.

Application Tracker
Track job applications with details such as company name, role, deadline, application status, and notes.

Saved Jobs
Save interesting job opportunities for later reference.

Placement Readiness Score
Automatically calculates readiness score based on user inputs and provides improvement suggestions.

Dark / Light Mode
User-friendly theme switching for better accessibilit

Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Browser LocalStorage
* Hash-based Routing

Getting Started

1. Clone or download the repository
2. Open `index.html` in your browser
3. Start using CareerBridge
   
No installation or additional setup is needed.

Data Storage
All user data is stored securely in the browser using **LocalStorage**.
No external server or database is connected.
 
 Project Status
This project is a frontend implementation intended for academic and portfolio purposes. Future improvements may include backend integration, authentication, and cloud database support.
